# FinPilot AI — Stock Intelligence & Portfolio Management Platform

Project location: E:\ashwin\stocks

## Overview

FinPilot AI is a production-ready financial intelligence platform built with Next.js 15, NestJS, Prisma PostgreSQL, Redis, and AI Assistant integration.

## Monorepo Layout

- `apps/frontend`: Next.js 15 App Router & Glassmorphism UI
- `apps/backend`: NestJS REST API Gateway & AI Recommendation Engine
- `packages/shared-types`: Shared TypeScript interface definitions
- `packages/shared-utils`: Financial metric calculators & formatters
